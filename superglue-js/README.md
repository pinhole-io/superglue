# superglue-js

Node.js bindings for [superglue](../superglue) via [napi-rs](https://napi.rs/). This package mirrors the surface area of [superglue-py](../superglue-py): `Client`, tools, hooks, guardrails, streaming, batching, conversations, and agents.

**Version:** `package.json` version matches the Rust core and other bindings (`projects/Cargo.toml` workspace). Run `../../scripts/sync-superglue-versions.sh` after bumping the workspace version.

## Install

```bash
npm install superglue-js
```

Prebuilt binaries cover Linux x86_64, Linux aarch64, macOS x86_64, and macOS Apple Silicon. On another platform, build from this repository. Each GitHub release also stores the `.node` files.

## Requirements

- Node.js 18+
- Rust toolchain when you build from this repository. An npm install uses the prebuilt binary for a supported platform.

## Build (from this repo)

```bash
cd superglue-js
npm install
npm run build
```

- `npm run build:native` — release `.node` addon.
- `npm run build:native:debug` — debug addon.
- `npm run build:ts` — TypeScript facade (`dist/facade.js`).

## Usage

### Native API (default `require`)

```js
const { Client, version } = require("superglue-js");

console.log(version());

const client = new Client(
  process.env.OPENAI_API_KEY,
  "gpt-5.4-nano-2026-03-17-mini",
  "https://api.openai.com",
  undefined,
  16,
  3,
  50,
  2000,
  2.0,
  undefined,
  60,
  15,
  3,
  8,
  undefined,
);

const outcome = await client.complete("Say hello in one short sentence.");
console.log(outcome.content);
```

See `index.d.ts` for full typings (generated by napi-rs).

### Facade (`superglue-js/facade`)

Named helpers and option objects:

```js
const {
  createClient,
  registerTool,
  registerGuardrail,
  GuardrailStage,
} = require("superglue-js/facade");

const client = createClient({ apiKey: process.env.OPENAI_API_KEY });

await registerTool(client, {
  name: "get_weather",
  description: "Get weather for a city.",
  parameters: {
    type: "object",
    properties: { location: { type: "string" } },
    required: ["location"],
  },
  execute: ({ location }) => ({ temp: 22, unit: "C", location }),
});

const out = await client.complete("What is the weather in Paris?");
```

For **custom guardrails**, use `registerGuardrail(client, (stage, content) => …)` from the facade. The raw `client.registerGuardrail` threadsafe callback passes `(err, stage, content)` **or** `(err, [stage, content])` depending on napi-rs tuple lowering; the facade normalizes both. Passing a plain two-argument `(stage, content)` function directly to `client.registerGuardrail` will mis-bind parameters. Handlers must be **synchronous** (return a string, or `throw` to block); do not use an `async` guardrail handler here — unlike tools, the native guardrail path does not await a Promise, and async wrappers can turn `throw` into an unhandled rejection.

## Tools and schemas

Unlike Python, there is no function-introspection layer: pass an explicit JSON Schema in `parameters` and a callback (sync or async) that returns a JSON object.

## Multi-provider and files

Chat models use `provider:model` (e.g. `openai:gpt-4o-mini`, `anthropic:claude-sonnet-4-20250514`). Set `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, etc., or pass `apiKeys` in `createClient` / `Client` options. Per-provider rate limits: `requestsPerSecondFor`. File attachments: `client.uploadFile(path)` and `messageWithFileBytes(text, filename, bytes)` on the facade. When tools are registered, `stream()` runs multi-round tool loops like `complete()`. Details: [`../superglue/docs/multi-provider.md`](../superglue/docs/multi-provider.md).
